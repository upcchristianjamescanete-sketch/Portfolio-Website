# 💻 Personal Portfolio Website

Welcome to my Personal Portfolio Website!

This website showcases my personal background, technical skills, projects, educational journey, certificates, and contact information. It serves as my online portfolio to present my knowledge, experiences, and development as an aspiring web developer.

## 🌐 Live Website

[Visit My Portfolio Website](https://upcchristianjamescanete-sketch.github.io/Portfolio-Website/)

## 📌 About the Project

This portfolio website was developed using HTML, CSS, and JavaScript. It features a clean, modern, and responsive design that allows visitors to explore my information and accomplishments.

The website also includes an interactive Light Mode and Dark Mode feature for a better browsing experience.

## ✨ Features

- **Home Section** – Introduction and personal information.
- **About Me** – Personal background and profile.
- **Skills Section** – Displays technical and programming skills.
- **Projects Section** – Showcases completed and ongoing projects.
- **Education Section** – Presents educational background.
- **Certificates Section** – Displays earned certificates and achievements.
- **Contact Section** – Provides contact information.
- **Dark and Light Mode** – Allows users to switch between different website themes.
- **Responsive Design** – Supports different screen sizes and devices.

## 🚀 How to Run the Project

1. Clone the repository:

   ```bash
   git clone https://github.com/upcchristianjamescanete-sketch/Portfolio-Website.git
   ```

2. Open the project folder.

3. Open `index.html` in your web browser.

4. Explore the different sections of the website.

## 🔄 How to Update the Website

After modifying the source code, use these Git commands:

```bash
git add .
git commit -m "Updated portfolio website"
git push
```

GitHub Pages will automatically update the published website after a successful deployment.
